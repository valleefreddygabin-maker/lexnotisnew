# Skills de design du projet

Claude Code charge automatiquement ces skills quand vous travaillez dans ce dépôt.

## Écrites pour LexNotis

| Skill | Rôle |
| --- | --- |
| `lexnotis-design-system` | Les règles du site : couleurs, typo, espacements, formes, animations, composants, et les sites de référence dont on s'inspire. |
| `concevoir` | `/concevoir <description en français>` : planifie, construit, teste et capture une page ou une section. |

## Emil Kowalski (design engineering, animations)

Source : https://github.com/emilkowalski/skills (commit `d16ebe6`), licence MIT (`_licenses/emilkowalski-skills-MIT.txt`).

`emil-design-eng` (la principale), `animate`, `review-animations`, `improve-animations`,
`find-animation-opportunities`, `animation-vocabulary`, `apple-design`, `pick-ui-library`,
`mobile-native`, `prototype`, `ask-sonner`. Non importées : `write-swift`, `animate-expo` (hors web).

## Taste Skill (goût, anti "look IA")

Source : https://github.com/Leonxlnx/taste-skill (commit `ce26fc2`), licence MIT (`_licenses/taste-skill-MIT.txt`).

`design-taste-frontend` (la principale, avec sa checklist de pré-vol), `redesign-existing-projects`,
`high-end-visual-design`, `minimalist-ui`, `full-output-enforcement`.

Mettre à jour : `npx skills@latest add emilkowalski/skills` et `npx skills@latest add leonxlnx/taste-skill`,
ou recopier les dossiers depuis les dépôts.
